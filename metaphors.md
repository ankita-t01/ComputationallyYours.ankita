# Codex metaphor log

Day 3. The five computational metaphors Codex proposed, the one you kept, and what it got wrong.

## Maya · Five computational metaphors

Five computational metaphors proposed by the coding agent for Maya, a messenger who hides secrets in artwork and poetry. No code.

1. **The painting as a hiding place.** A message determines small details in a painting: the position of birds, the number of flowers, or a break in the border. To most people, it remains a landscape. *Could fail:* if every detail is a symbol, the painting may look too deliberate and reveal that a message is there.

2. **The poem as a key.** A verse tells the receiver which details of a painting to read, and in what order. A different verse could lead to a different meaning. *Could fail:* the poem might make the code so complicated that the receiver cannot read it in time.

3. **The journey as a network.** Maya carries messages between contacts inside and outside Raigad. Each contact knows only the next person in the chain. *Could fail:* a diagram of routes might explain how the message travels without showing what makes Maya’s artwork necessary.

4. **The border as a sequence.** Marks along the edge of a painting follow a rule that encodes a short message. The pattern continues to look decorative as its details change. *Could fail:* a repeated code could be recognised, even by someone who does not know what it says.

5. **The letter as two readings.** A written verse has an ordinary meaning when read aloud, but selected words form another message for the intended receiver. *Could fail:* if the hidden reading controls every word, the poem may sound unnatural.

**Kept: 1, the painting as a hiding place.** Maya would choose it because a painting gives her a reason to carry the message in the open. The receiver knows which details to notice; someone else sees a landscape. For the generative artwork, each message would change the placement or number of a few details while the image remains a painting.

**What the agent got wrong.** It treated secrecy as a puzzle to be solved. My first suggestion replaced letters directly with symbols, which could make the code too visible. Maya needs the painting to pass as an ordinary object before anyone can read it. The proposed symbols are also inventions for her story; they should not be presented as a historical code without evidence.
